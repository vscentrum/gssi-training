# VSC Training: Getting Scientific Software Installed

The Getting Scientific Software Installed training (or GSSI in short) is
jointly organised by the HPC support teams of the institutions that are part
of the [Vlaams Supercomputer Centrum](https://www.vscentrum.be/). It helps
VSC users to select and use the right tools to get their software installed
on the VSC clusters.

The subdirectories of this repository contain code examples that are used
during the training and allow participants to apply what they learned during
the training in practice. An overview of upcoming and past training runs
(including slides and video recordings of presentations) is available
[here](https://vscentrum.github.io/gssi-training).
