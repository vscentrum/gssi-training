# Contents of this directory

* `environment.yml`

Conda environment file for installing tblite

* `install.sh`

Script to build and test the tblite container with hpc-container-wrapper and the Conda environment file

* `run.sh`

Script to run the tblite container with any given input file
e.g. `exercises/containers/tblite/demoscripts/tblite-single-point-GFN2-xTB.py`
