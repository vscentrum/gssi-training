# Contents of this directory

* `tblite-0.4.0.def`

Apptainer definition file for building the tblite container

* `install.sh`

Script to build and test the tblite container with the Apptainer definition file

* `run.sh`

Script to run the tblite container with any given input file
e.g. `exercises/containers/tblite/demoscripts/tblite-single-point-GFN2-xTB.py`
